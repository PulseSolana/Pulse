# Pulse Runbook

## What Pulse Is For

Pulse helps the operator decide whether short-horizon aggressive flow is still compounding or already decaying.

## Daily Operator Loop

1. Run `bun run dev`.
2. Read the dashboard for the top pulse candidate.
3. Confirm breadth, liquidity migration, and slippage all support continuation.
4. Escalate only the names where the burst still looks exitable.

## What Gets Promoted

- broad aggressive flow
- improving liquidity support
- manageable slippage pressure

## What Gets Demoted

- concentrated one-wallet bursts
- moves that outrun topbook depth
- pulses already shifting into cooldown
